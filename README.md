# GithubUsers App 

## Overview
A Swift-based application that showcases a list of GitHub users with seamless integration of **SwiftUI** and **UIKit**.

## Features
### Home Screen
- Browse a list of GitHub users on a interface built with SwiftUI.

### User Details
- Dive deeper into each user's profile with a detailed view.
- Includes information such as: location, number of followers, following
- Built using UIKit for advanced customization.

### Hybrid Architecture
- Demonstrates the power of combining SwiftUI and UIKit to create a cohesive user experience.

### Persistent Data Storage
- Leverages **CoreData** to store fetched user data locally.
- Enables instant display of previously fetched data upon app relaunch, ensuring a smooth and efficient user experience.
